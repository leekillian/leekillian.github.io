Privacy Policy

Athenaeum Backup is a personal-use application operated solely by its owner.

Google Drive Access

The application uses Google OAuth to access Google Drive files created through the application. This access is used to create, read, update, and maintain personal backups.

Data Storage and Security

Backup contents are encrypted locally using Restic before upload to Google Drive. Authorization credentials are stored on the owner's computer.

Data Sharing

Personal backup data is not sold, used for advertising, or intentionally shared with unrelated third parties. Google Drive provides cloud storage and GitHub hosts this informational website.

Website

This website does not request personal information. Its hosting provider may process technical access information according to its own privacy policy.
